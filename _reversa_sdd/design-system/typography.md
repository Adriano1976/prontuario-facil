# Tipografia

> Gerado por reversa-design-system em 27/08/2026.
> Nível de Confiança: 🟡 Inferido pelo padrão Tailwind CSS e Radix UI.

O sistema não possui declaração explícita de fontes customizadas (ex: `@font-face` ou Google Fonts no `tailwind.config.js`). 

## Fonte Base
A aplicação utiliza a pilha de fontes sans-serif padrão do sistema oferecida pelo Tailwind CSS (`font-sans`), que se adapta ao SO do usuário:

`ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`

## Escala de Tamanhos e Pesos
Seguindo a base do Tailwind, estão disponíveis:
- **Tamanhos (text-):** `xs` (0.75rem), `sm` (0.875rem), `base` (1rem), `lg` (1.125rem), `xl` (1.25rem), `2xl` até `9xl`.
- **Pesos (font-):** `light` (300), `normal` (400), `medium` (500), `semibold` (600), `bold` (700).

*(Lacuna: Não há customizações de tipografia estabelecidas no arquivo CSS local ou no tailwind config. O estilo 'new-york' do Shadcn tende a favorecer tamanhos ligeiramente menores e visuais mais sóbrios e densos).*
