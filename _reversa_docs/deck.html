Prontuário Fácil

Prontuário eletrônico aderente à LGPD para clínicas médicas. Gestão centralizada de pacientes, consultas, agendamentos e exames.

Ver mini-site → Use as setas para navegar
Propósito

Digitalizar o fluxo de atendimento

Aplicação web (SPA React/Vite) que provê a gestão completa de pacientes, consultas, agendamentos e exames, com segurança e padronização via arquitetura BaaS (Base44 + Supabase).

Decisões fundadoras

Quatro escolhas estruturais

D1 · Adoção da Base44 (BaaS) com Supabase

Backend 100% gerenciado: banco, autorizações (RLS) e APIs CRUD fora do código da aplicação.

D2 · Arquitetura Frontend SPA (React + Vite)

Roteamento e estado vivem no cliente; chamadas assíncronas via TanStack Query; sem SSR.

D3 · UI com Tailwind CSS e Radix UI (shadcn)

Estilização por classes utilitárias e primitivas acessíveis; sem CSS puro por componente.

D4 · Estrutura híbrida de módulos (Domain / Pages)

Rotas em config central; lógica separada por domínio (components/appointments, components/medical).
