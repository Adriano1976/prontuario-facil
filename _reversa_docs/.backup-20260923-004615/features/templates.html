📝 Templates

Modelos de documentos médicos com variáveis interpoladas para agilizar o atendimento.

Entidade: Template Admin only 7 tipos
Visão geral

Modelos que aceleram o atendimento

O módulo de Templates gerencia modelos pré-definidos de texto para documentos médicos (receitas simples, controladas, atestados, solicitações de exame), agilizando o atendimento clínico.

Regras de negócio
BR-T01Todo template exige name, type e content.
BR-T02O tipo deve pertencer ao enum de 7 valores permitidos (ex: receita_simples, atestado, anamnese).
BR-T03Criação e exclusão restritas a administradores (role == admin).
BR-T04Variáveis são interpoladas no salvamento. Contextuais como {DIAS_AFASTAMENTO} podem ser resolvidas pelo contexto ou exigir preenchimento manual.
Estrutura de dados
