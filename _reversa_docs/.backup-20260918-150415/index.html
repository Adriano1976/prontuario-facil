Decisões fundadoras

Por que foi construído assim

☁️
Base44 (BaaS) + Supabase

Backend 100% gerenciado: banco, RLS e CRUD fora do código da aplicação.

⚛️
SPA React + Vite

Roteamento e estado no cliente, com TanStack Query para chamadas assíncronas.

🎨
Tailwind + Radix (shadcn)

UI por classes utilitárias e primitivas acessíveis.

🧩
Domínio vs Pages

Rotas no config central; lógica separada por domínio de negócio.
