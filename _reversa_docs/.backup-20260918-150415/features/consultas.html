Visão geral

O registro clínico do atendimento

O módulo de Consultas gerencia o registro clínico do atendimento médico, englobando anamnese, sinais vitais, hipótese diagnóstica (CID-10), plano de tratamento e emissão de prescrições e exames.

Regras de negócio
BR-C01Toda consulta deve estar obrigatoriamente vinculada a um patient_id válido.
BR-C02O status segue o ciclo: agendada → em_andamento → concluida (ou cancelada).
BR-C03Em prescrições vinculadas, medications só é preenchido para tipo receita. Cada item contém nome, dosagem, frequência, duração e instruções. Para outros tipos, a seção fica oculta.
