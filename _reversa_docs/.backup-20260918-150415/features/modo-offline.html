🔌 Modo Offline

Unit transversal: runtime alternativo com mock client e localStorage, ativado por VITE_OFFLINE=true.

Unit transversal Sem RLS localStorage
Visão geral

Rodar a SPA sem backend

O modo offline permite rodar a SPA sem o backend Base44, com todos os dados no localStorage do navegador. A UI é equivalente ao modo online: as pages continuam chamando base44.entities.<X>.<op>() sem saber se falam com o SDK real ou com o mock.

Regras de negócio
BR-OFF01Ativado exclusivamente por VITE_OFFLINE=true em tempo de build (import.meta.env). Sem toggle em runtime.
BR-OFF02Quando ativo, base44Client.js exporta o retorno de createMockClient() em vez do createClient() do SDK.
BR-OFF03O AuthContext autentica imediatamente como OFFLINE_USER (demo-user-001, Dra. Demo).
BR-OFF04Cada entidade persiste em mock_db_<EntityName>; na primeira leitura, se ausente/corrompida, é semeada de mockSeed.
BR-OFF05Operações expostas: list, filter, create, update, delete, UploadFile, auth.me/logout/redirectToLogin, appLogs.logUserInApp.
BR-OFF08filter(conds) usa comparação estrita (===); sem suporte a in, contains, gte, lte, ne.
BR-OFF09sort aceita string única (field asc ou -field desc), 1 campo, sem tie-breaker determinístico.
BR-OFF10O modo offline não aplica RLS: todos os registros são visíveis e editáveis. 🟡
